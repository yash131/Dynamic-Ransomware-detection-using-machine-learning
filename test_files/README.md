# Test files

| File | What it is | Expected |
|---|---|---|
| `benign_sample.bin` | Inert header-only PE stub with the header profile of a modern MSVC-built tool | Benign |
| `simulated_malicious_sample.bin` | Inert header-only PE stub with a legacy/packed-style header profile. **Not real malware.** | Malicious |

Both are generated by `python scripts/make_test_files.py`. They contain **no executable code**: section bodies are zero bytes plus a text
marker, the entry point is 0, and the `.bin` extension prevents accidental launching. Antivirus products should not flag them (if one does, it is a heuristic false positive).

"Expected" describes what the trained models output for these header values; it is not hard-coded anywhere. The malicious stub's profile was chosen after probing the
models, so treat it as a pipeline smoke test, not as a measure of detection accuracy.
